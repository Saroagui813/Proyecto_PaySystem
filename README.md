# PaySystem

Aplicación de escritorio que simula la administración de cuentas y pagos de una entidad bancaria, con datos ficticios.
Proyecto de fin de ciclo de 2º DAM (curso 2026-2027).

**Autor:** Samuel Romero Aguilera

## Estado del proyecto

En fase de anteproyecto. Pendiente de aprobación por el profesorado; todavía no hay código.

## Qué hará

- Crear clientes y cuentas ficticias.
- Registrar ingresos, retiradas y transferencias entre cuentas. Una transferencia actualiza las dos cuentas a la vez o no cambia ninguna.
- Consultar y filtrar un historial de movimientos que no se puede editar.
- Bloquear y reactivar cuentas.
- Acceso con roles (operador y administrador) y registro de auditoría de las acciones.

No se conecta a bancos ni mueve dinero real.
